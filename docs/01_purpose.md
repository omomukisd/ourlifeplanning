# 01. 目的・スコープ定義書（v0.3）

> **このリポジトリは公開されています。** 家族構成・年齢・収入・資産額などの個人情報は、
> ドキュメント・コード・テストデータのいずれにも書かないこと。

## 1. 背景
子育て・住宅ローン・老後を見通し、「今どれだけ使ってよいか」「将来どうなるか」を
世帯で同じ数字を見ながら判断したい。

## 2. 目的（このアプリで答えたい問い）
| # | 問い | 判断に使う場面 |
|---|------|----------------|
| Q1 | **老後資金は足りるか？** 何歳まで資産が尽きないか | 貯蓄・投資額の見直し |
| Q2 | **趣味に使えるお金はいくらか？** 毎月いくらまで使ってよいか | 日々の支出、旅行・趣味の計画 |
| Q3 | **FIREはできるか？** 何歳で、いくらの資産があれば可能か | 働き方・キャリアの選択 |

## 3. 利用者・利用環境
- 利用者：世帯の大人（複数人が閲覧・編集できる）
- 端末：スマホがメイン
- 形態：Webアプリ（スマホ対応）またはiOSアプリ。※システム設計フェーズで決める

## 4. 成功の基準
### A. 問いに答えられるか（アウトプットの基準）
- [ ] S1: Q1〜Q3に、**それぞれ1画面・3タップ以内**で数字で答えが出る
- [ ] S2: 標準と悲観の**少なくとも2シナリオ**で答えが出る
- [ ] S3: 答えの根拠となる**前提値が画面で確認・変更できる**

### B. 使い続けられるか（運用の基準）
- [ ] S4: 定期更新（資産残高の入力など）が**月1回・5分以内**で終わる
- [ ] S5: 世帯の**どの利用者のスマホからも同じデータ**が見られる

### C. 行動につながるか（効果の基準）※リリースから半年後に振り返る
- [ ] S6: 世帯で数字を見ながら、お金の話し合いを**年1回以上**している
- [ ] S7: このアプリの数字をもとに、具体的な判断を**1つ以上**している

## 5. スコープ
### 対象（やること）
- 世帯の年単位キャッシュフロー・資産推移のシミュレーション（〜100歳）
- ライフイベント（教育、住宅、車、退職など）の反映
- 趣味予算・FIRE可能年齢の算出
- シナリオ比較

### 対象外（やらないこと）※初期段階
- 家計簿機能（支出明細の記録・分類）
- 銀行・証券口座との自動連携（家計簿アプリの個人向けAPIは一般に提供されておらず、CSV書き出しも有料機能のことが多いため。将来の検討事項）
- 個別銘柄・金融商品のアドバイス
- 税・社会保険の厳密な計算（簡易モデルにする）

## 6. 方針として決まったこと
| 項目 | 方針 |
|------|------|
| 教育方針 | 公立／私立は未定 → シナリオで切り替えられるようにする |
| 退職年齢 | 未定 → 変数として変えられるようにする |
| FIRE | 完全リタイアとサイドFIREの両方を比較できるようにする |
| 趣味予算 | 毎月の額を先に確保し、残りを貯蓄・投資に回す |
| 外部連携 | 初期は手入力 |
